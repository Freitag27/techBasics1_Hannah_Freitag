

if you need help with getting any of the endings, consult this guide. There is not much context to try not to spoil too much.
Still: Spoiler warning :)

Endings: 
"Left before entering the cave":
select 'leave' when MrMcMoney asks whether you want to leave or stay

"Picked up the poisonous worm": 
select 'stay' when Mrmcmoney asks, in the first room of the cave, find the little green dot that shows '???' whenever you hover over it and try to pick it up (double click)

"Got stuck in the stalactites": 
select 'stay', in the first room pick up the bracelet but not the stones, then map the cave. In the next room, try to map the cave.

"Fell asleep in the dark": 
select 'stay', pick up the stones and do NOT pick up the bracelet in the first or the skull in the second room or leave both. You won't be able to help the spirit in the last room and it will get angry because of that.

"Left the map with the skeleton": 
select 'stay, pick up the stones, bracelet',then map the cave. In the next room pick up the skull,then try to map the cave.Click the stones to break the stalactites. In the third room, give the bracelet and the skull to the skeleton, then select 'leave map'

"Mapped the cave for Mr. McMoney": 
select 'stay, pick up the stones, bracelet',then map the cave. In the next room pick up the skull,then try to map the cave.Click the stones to break the stalactites. In the third room, give the bracelet and the skull to the skeleton, then select 'map room3'
